### GT Movies Store

- **GT Movies Store** is a full-stack web application designed to simulate an online movie rental and purchasing platform.
- **Home Screen:** Allows users to browse available movies with posters, titles, and descriptions.
- **Movie Details:** Displays a movie's synopsis, rating, genre, and rental or purchasing options.
- **Search & Filter:** Allows users to search for movies by title and filter movies by genre.
- **Cart & Checkout:** Allows users to add movies to their cart and calculates the total cost.
- **Confirmation Page:** Displays an order summary after completing checkout.

### Process

- Followed an **iterative Agile development approach**, building and testing features incrementally.
- Used the given user stories to define the functionality and requirements for each feature.
- Broke larger features into smaller tasks and tested each component throughout development by following the textbook.
- Resolved questions and doubts through **debugging, documentation, experimentation, and testing**.
- Continuously tested features against the user stories and refined the application throughout development.
